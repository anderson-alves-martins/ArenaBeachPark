# Arena Beach Park

Site institucional da Arena Beach Park, publicado no ChatGPT Sites.

## Estrutura

- `dist/index.html` — página inicial.
- `dist/cardapio.html` — página do cardápio, incorporando o cardápio digital atual de `www.arenabeachpark.com.br`.
- `.openai/hosting.json` — identificação e configuração do site no ChatGPT Sites.

O projeto do cardápio continua no repositório próprio `cardapio-arena-beach-park`; esta página o exibe dentro do site institucional.

## Visualização local

Abra `dist/index.html` no navegador ou use uma extensão como Live Server no VS Code.
