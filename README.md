# Arena Beach Park

Site institucional da Arena Beach Park, publicado pelo GitHub Pages em [www.arenabeachpark.com.br](https://www.arenabeachpark.com.br/).

## Estrutura

- `dist/index.html` — página inicial.
- `dist/cardapio.html` — página do cardápio, incorporando o app mantido no repositório `cardapio-arena-beach-park`.
- `.github/workflows/deploy-pages.yml` — publica automaticamente a pasta `dist/` a cada atualização da branch `main`.
- `.openai/hosting.json` — identificação e configuração do projeto no ChatGPT Sites.

O cardápio continua hospedado no repositório próprio e é carregado dentro da página institucional.

## Visualização local

Abra `dist/index.html` no navegador ou use uma extensão como Live Server no VS Code.
